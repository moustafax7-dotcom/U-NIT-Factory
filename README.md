# U-NIT Clothing Factory • V6

Static HTML, CSS and JavaScript. No build step.

- `index.html` — page content and bilingual copy
- `css/site.css` — layout, responsive styles and RTL
- `js/products.js` — catalogue, model photos and colours
- `js/site.js` — catalogue interactions and language selection
- `js/order-form.js` — fields, validation, photos and submission
- `js/config.js` — preview mode, order endpoint and contact links
- `apps-script/Code.gs` — saves website orders and emails the factory

For Google setup and live verification, use [the Arabic installation guide](apps-script/README_AR.md).
