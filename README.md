# U-NIT Website V6
Single-page HTML/CSS/JS, no build step. Open index.html.

FORM: js/config.js has formPreview: true, so the page shows the new in-page form as a NON-SENDING design preview (a banner says so).
Before publishing: fill formEntries (entry.NNNN ids from the Google Form pre-filled link), set formPreview to false.
While formEntries is empty and formPreview is false, the embedded Google Form is shown instead.
